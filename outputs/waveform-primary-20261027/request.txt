## Synthetic task

Generate independent trajectories using

X_i(t_j) = A_i [sin(theta_i(t_j)) + 0.3 sin(2 theta_i(t_j) + psi_i)] + epsilon_ij,

theta_i(t) = 2 pi f_i t + phi_i.

Draw independently for each trajectory:

- A_i ~ Uniform(0.7, 1.3)
- f_i ~ Uniform(0.6, 0.9)
- phi_i ~ Uniform(0, 2 pi)
- psi_i ~ Uniform(0, 2 pi)
- epsilon_ij ~ Normal(0, 0.02²), independently across observations.

Amplitude, frequency, and phases remain fixed within each trajectory. Models must not receive these latent parameters.

Use these initial settings:

- Original observation spacing: 0.1.
- History: 25 observations at times 0 through 2.4.
- Forecast: 8 observations at times 2.5 through 3.2.
- Densification factor: 2, giving spacing 0.05.
- Primary training set: 1,024 independent trajectories.
- Separate validation and test sets: 256 and 1,024 independent trajectories.
- Three paired experimental seeds, sharing each seed’s dataset and forecaster initialization across methods.

The hypothesis is that learned interpolation preserves waveform curvature and expresses phase/frequency structure in a form that helps finite-data forecasting. Generated history points do not add information about the actual future, so do not describe any improvement as recovering information unavailable in the observed history.
